## 1. 现状分析

### 1.1 产品与实现

Mana 是一个本地优先的开发项目管理桌面端：项目、项目组、文档在同一窗口内登记、归类、查阅。v1.0 已完成项目 / 项目组 / 文档 CRUD、Markdown 编辑与预览、首页统计、搜索筛选、删除级联确认、快捷键与无边框窗口。

现版本界面（`docs/screens/`）采用「紫罗兰 + 4/6px 小圆角 + 1px 边框 + 白卡片」的企业紧凑风，功能完整，但视觉与信息结构存在以下问题。

### 1.2 主要问题

| # | 问题 | 具体表现 |
|---|---|---|
| 1 | **导航双层重复** | 左侧 228px 导航承担「首页 / 项目组」；顶部 56px 栏又重复标题与主操作；项目组页里再叠一层 280px 组列表，一屏出现三层纵向导航。 |
| 2 | **卡片墙吃掉首屏** | 首页 4 张统计卡 + 两个卡片容器 + 文档卡，边框与留白占去大量高度；真正要看的项目表被压到 410px 高的卡片里。 |
| 3 | **颜色与标签噪声** | 主色紫、青、橙、绿同时出现；标签是彩色药丸，版本是另一种描边胶囊，文档类型又是第三种色块。同屏 5 种以上色相，扫视成本高。 |
| 4 | **详情页权重失衡** | 项目元信息占 320px 固定右栏，与「看文档」这个主任务同权重；路径用 9.6px 等宽字挤在输入框式容器里，是开发者最需要的信息却最弱。 |
| 5 | **编辑器像表单** | 工具栏是 H1/H2/B/I 文本占位按钮，与 30px 分段控件、链接输入、保存按钮混在标题区；源码与预览两栏没有行号、纸面或层级，像被拉长的 TextArea。 |
| 6 | **空态与反馈靠文案** | 空表格、toast、错误都挤在边缘；删除弹层只说明「不可恢复」，没有级联数量的视觉强调。 |

### 1.3 可重设计的边界

- 只有 MyGo 原生控件：`ui.Row/Column/Box/Text/Icon/Table/SearchField/Scroll/Button/Theme/DialogBase`，没有 CSS、阴影、动效弹簧。
- 现有功能与交互不应减少：四页结构、弹窗、快捷键、深链返回、级联删除说明都要保留。
- 字体只能使用本地已安装的商用字体：Inter、Noto Sans SC、JetBrains Mono；不能随包分发字体文件。
- 图标必须继续使用 adago-design 内置 SVG（24 网格、1.7 描边、currentColor），不能用 emoji 或字符代替。

## 2. 重设计方向：索引卡 · INDEX

把「后台管理模板」改成**一张可检索的本地索引卡**：

- **一条工具栏、一层目录、一张记录纸。** 深色 68px 图标轨承担全局导航；252px 上下文目录随页面变化；主区用 34px 内边距 + 发丝线组织，不再用卡片包围一切。
- **路径、版本、时间是主角。** 用 JetBrains Mono 统一编号、版本、路径与更新时间；表格首列加 `01—06` 序号，项目名与路径上下两行。
- **朱砂只做强调。** 当前选中、主操作、危险操作使用 `#AE4229`；标签改为「文字 + 中点」或细描边小徽标，不再使用彩色药丸。
- **纸感但不拟物。** 暖纸底 `#F0EBE0`、墨字 `#1B1913`、发丝线 `#D6CFBE`；不模拟纸张纹理、胶带或手写体。

保留「左导航 + 顶部操作」的单窗口结构，但把左导航拆成「图标轨 + 目录」，去掉顶部重复标题；所有新布局都能用 MyGo 的 Row/Column/Box 直接绘制。

## 3. 设计系统

### 3.1 颜色

| Token | 值 | 用途 |
|---|---|---|
| Paper | `#F0EBE0` | 窗口外层 / 画布底 |
| Sheet | `#FCFAF5` | 主内容区 |
| Sheet 2 | `#F6F1E6` | 目录栏、表头、状态条 |
| Ink | `#1B1913` | 标题与正文 |
| Ink 3 | `#7B7464` | 次要说明、时间 |
| Line | `#D6CFBE` | 发丝线、输入框描边 |
| Seal | `#AE4229` | 当前选中、主按钮、链接、印章 |
| Seal soft | `#EFDFD7` | 选中底、危险图标底 |
| Moss / Amber / Indigo | `#4E6444` / `#8C6227` / `#33586B` | 文档类型与状态（低饱和，只做小面积点缀） |

> `docs/screens/` 里的紫罗兰主色、青/橙标签不再作为主色；数据里的组标识色可以继续保留，但只以小方块出现。

### 3.2 字体与字阶

- UI：`Inter`（拉丁）+ `Noto Sans SC`（中文），系统字体兜底。
- 等宽：`JetBrains Mono`（路径、版本、编号、字数、快捷键）。
- 字阶：Display 29/34 · 700；Title 22/28 · 700；Section 13/20 · 600；Body 12.5/20 · 400；Small 10.5/18；Micro 9.5/14 + 0.16em；Mono 10/18。
- 等宽数字使用 `font-variant-numeric: tabular-nums` 的等价思路：MyGo 中用固定字宽字体即可。

### 3.3 间距、边界、层级

- 4px 基线；内容区左右 34px；栏间距 32px；目录栏 252px；图标轨 68px；窗口条 38px；状态条 30px。
- 控件与弹层圆角 2px；表格行高 54–63px；项目组页行高自适应铺满。
- 容器只用 1px 发丝线；**卡片不投影**。仅弹层使用 56% 墨色遮罩 + 一层柔和阴影。
- 图标 24 网格、1.7 描边，来自 adago-design `design_icons`；不使用字符图标。

## 4. 页面方案

### 4.1 应用外壳

- **顶部 38px 墨色条**：品牌 M 印记、MANA / PROJECT INDEX、本地 SQLite 状态、`CTRL K` 命令提示、设置与头像；窗口控制建议回归系统标题栏或收进此处，不再与主操作争位置。
- **68px 图标轨**：首页 / 项目组 / 统计 / 搜索 / 数据索引，底部为数据库与设置；当前项用朱砂色内阴影 + 浅朱砂底。
- **252px 上下文目录**：首页显示最近项目与文档类型分布；项目组页显示组列表；项目详情页显示组内项目；编辑器显示项目文档。同一时刻只有一处「当前在哪」。
- **主区**：页眉（面包屑 + 标题 + 右侧操作）+ 一条账本式统计（或筛选行）+ 内容 + 30px 状态条。

### 4.2 首页

- 四张统计卡改为一条 **4 格账本**：项目 / 项目组 / 文档 / 本周更新，数字 30px 等宽，附一行口径说明；高度从 88+卡片边距降到 92px 且无卡片框。
- 最近更新项目表：`01—06` 序号、项目名 + 一句话描述、版本徽标、标签文本、相对时间、行菜单。
- 表下增加 **最近文档** 双列条（4 条），右栏保留项目组与本周回顾；去掉原「项目组概览 + 文档卡」的重复容器。
- 首屏信息密度提高，不依赖卡片分层。

### 4.3 项目组管理

- 去掉「全局侧栏 + 顶部标题 + 组列表」的三层导航：全局只留图标轨，组列表独占目录栏。
- 右栏头部：组标识色小方块、组名、描述、`5 项目 / 5 文档 / 2 小时前`，右侧编辑、删除、新建项目。
- 「项目 / 文档」用下划线页签；筛选行只保留搜索、标签、排序三个文本控件。
- 表格列：序号、项目/路径、版本、标签、更新、行菜单；5 行自动铺满可用高度，脚注与组文档条固定在底部。

### 4.4 项目详情

- 目录栏变成 **项目目录**：当前组内项目列表，当前项目高亮，底部「返回项目组」。
- 页眉：项目名 + 版本徽标；描述；标签、路径（带复制）、文档数、更新时间集中成一条 meta 行。
- 主列：项目文档表（标题 / 类型 / 字数 / 更新）+ 底部 **文档预览**（标题、两行摘要、Markdown / 字数 / 时间、打开文档）。
- 右栏 **记录卡**：所属组、版本、路径、创建/更新、标签、备注、文档分布与两项统计；用左侧发丝线分隔，不再是一张独立卡片。

### 4.5 文档编辑

- 标题区只有：可编辑标题 + 类型下拉 + 归属/保存状态 + 关联链接；右侧放「源码 / 预览」分段、保存主按钮、删除。
- 去掉占位式 H1/H2/B/I 工具条；编辑区是一张 **写作纸**：左侧行号槽 + 等宽 Markdown 源码，右侧渲染预览（标题、编号小节、列表、表格、引用）。
- 底部状态条：Markdown、UTF-8、字数、保存状态、`CTRL S`。
- 窄窗口下分段控件可切单栏，保持 1120 宽的可用性。

### 4.6 弹层与状态

- 新建项目弹层 660px：顶部 3px 朱砂条、NEW RECORD 小标、标题与说明、字段标签在上方、焦点/错误状态、路径即时提示、底部快捷键与主/次按钮。
- 删除确认 486px：危险图标、标题、会受影响的级联数量（移到未分组 / 删除组文档），底部确认按钮使用危险色。
- 空状态：空白索引卡 + 「还没有项目」+ 新建项目 / 新建项目组两步操作。
- 最小窗口 1120×720：目录栏收至 240px，隐藏标签列，详情右栏收至 288px，文档预览折叠，不出现横向滚动。

## 5. MyGo 落地映射

| 设计部件 | MyGo 实现建议 |
|---|---|
| 墨色顶条 | `ui.Row` + `Background` + `Padding`；窗口拖动区域 `DragWindow()` |
| 图标轨 | `ui.Column` + 自绘 46px `ui.Box` 导航项；选中 `Background(colSealSoft)` + `InsetShadow(2,0,0,0,colSeal)` |
| 上下文目录 | `ui.Column` + `Width(252)` + `BorderWidth(0,0,1,0)`；行高 34–44 |
| 账本统计 | `ui.Row` + 4 个 `Grow(1)` 单元；数字用 `FontSize(30)` + JetBrains Mono |
| 表格 | 继续用 `ui.Table`；去掉外层卡片，表头 30px、行高 54–63px、首列序号用 Mono |
| 标签 | 文本 + 中点（`ui.Text`）或细描边 `ui.Row`；不再生成彩色药丸 |
| 搜索 | `ui.SearchField`（30–32px 高）配 `Focus` 快捷键；全局搜索仍走命令面板 |
| 写作纸 | 左右 `ui.Row`；源码用 `ui.TextAreaBase` + 自绘行号列；预览用 `markdown.View` |
| 记录卡 | `ui.Column` + `BorderWidth(0,0,0,1)` + 字段行；统计用 Mono 数字 |
| 弹层 | `ui.DialogBase` + 2px 圆角；遮罩 `ui.RGBA(23,21,15,0.56)`；仅此处保留轻阴影 |
| Toast | 底部居中 34px 墨色条，2.4s 消退 |
| 主题 | 重写 `internal/app/theme.go`：Background/Sheet/Ink/Line/Seal 映射到 `ui.Theme`；固定浅色，深色主题列入 v1.1 |

### 落地文件

- `internal/app/theme.go`：替换色板与半径 / 字号基线。
- `internal/app/shell.go`：删除 228px 侧栏与 56px 顶部标题，改为 icons rail + context panel + 38px 顶条。
- `internal/app/widgets.go`：go 账本单元、文本标签、记录行、印章、状态条等小组件。
- `internal/app/home.go`、`groups.go`、`project.go`、`editor.go`、`dialogs.go`：按本方案重排。
- `design/README-v2.md`、`design/screens-v2/`：本设计与交付图。
